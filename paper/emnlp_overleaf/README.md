# EMNLP Overleaf Draft

Entry point: `main.tex`.

This folder is structured for the ACL/EMNLP Overleaf template. If `acl.sty` is not present locally, create a new project from the official ACL/EMNLP Overleaf template and upload/copy these files into it.

The draft is anonymous review mode via `\usepackage[review]{acl}`.

Target format: EMNLP main-conference short paper. Current EMNLP/ARR guidance lists short papers as 4 pages of content, with references and appendices outside the content page limit; accepted papers receive one extra content page for revisions. This draft is written as a focused short-paper negative result about member-derived label representations.

Local status: expanded first draft with abstract, introduction, related work, data, methods, results, discussion, limitations, conclusion, figures, tables, and bibliography entries. Local page count has not been verified because no local LaTeX engine/style installation was available.
